# Code of Conduct

Loom is a place for careful work on a tool that changes people's computers. Be respectful, assume
good intent, and keep the conversation about the software.

## Expected

- Be kind in issues, pull requests and review.
- Disagree about the change, not the person.
- Give people room to ask questions.
- Credit the work you build on.

## Not accepted

- Harassment, personal attacks or sexual language aimed at someone.
- Publishing someone's private information.
- Trolling, baiting or sustained disruption.

## Reporting

If someone is breaking these expectations, contact the repository owner through GitHub rather than
escalating it in public. Reports are handled in private. The owner may warn, or remove, anyone who
keeps breaking them.

This policy applies to the repository, its issues and pull requests, and any other space set up
for Loom.
